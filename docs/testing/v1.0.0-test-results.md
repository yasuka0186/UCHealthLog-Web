## セキュリティ設定のコード確認

- `wrangler.jsonc`は`dist/`を配信対象とし、`single-page-application` fallbackを設定しています。
- `public/_headers`はCSP、`X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy`、`Permissions-Policy`を設定しています。
- CSPの`connect-src 'none'`により、配信後のアプリからの外部接続を許可しない方針です。
- ViteはProduction source mapを生成しない設定です。

## 残っている制限事項と記録上の不足

- ログイン、クラウド同期、端末間同期、サーバー側バックアップはありません。
- IndexedDBとバックアップZIPにアプリ独自の暗号化はありません。
- サイトデータ削除やオリジン変更でデータを失う可能性があります。
- PWAとオフライン用静的アセットキャッシュはv1対象外です。
- Yahoo! JAPANアプリなどのアプリ内ブラウザは正式対応対象外です。
- 公開URL、Edge・Safariのversion、本番確認時の日時、レスポンスヘッダー値、Networkタブの記録はリポジトリから確認できません。
- GitHubリポジトリの既定ブランチは確認時点で`feature/phase-1-foundation`となっており、開発要件の`main`運用と一致していません。
