# UCHealthLog Web v1.0.0 リリースノート

## 概要

UCHealthLog Web v1.0.0は、潰瘍性大腸炎（UC）の人が日々の体調を記録し、履歴やグラフで振り返るための初回Webリリースです。iOS版MVP ver.1.04の主要機能をWeb向けに移植し、ブラウザ内保存、バックアップ、レスポンシブ表示などWeb固有の要件へ対応しました。

本アプリは記録を補助するもので、医療診断、治療判断、治療提案を行うものではありません。

## 主な機能

- 体調、腹痛レベル、トイレ回数、血便、服薬、自由メモの日別記録
- 月間カレンダーと体調マーカー
- 履歴一覧、詳細表示、編集、削除
- 朝・昼・晩・間食ごとの食事写真の保存と置換
- 7日・14日・30日のトイレ回数グラフ、平均・最高・最低の表示
- 同じローカル日付の記録を1件に保つupsert

## Web版固有の機能

- スマートフォン、タブレット、PCに対応するレスポンシブUI
- OS設定に連動するライト／ダークモード
- 記録と写真を含むZIPバックアップのエクスポート・インポート
- ブラウザストレージの概算使用量表示
- 対応ブラウザでの永続ストレージ要求と、容量超過時のユーザー向け案内
- SPAのdeep link対応

## データ保存方式

記録と食事写真は、利用中のブラウザのIndexedDBへ保存されます。記録と写真は別ストアで管理し、同日重複の防止、写真置換、関連写真を含む削除をDexie transactionで処理します。写真は画面とバックアップ境界では`Blob`、IndexedDB内部ではSafari/WebKit互換性のため`ArrayBuffer`として保存します。

ログイン、クラウド同期、端末間同期、サーバー側バックアップはありません。ブラウザ、端末、ブラウザプロファイルが異なる場合、データは自動共有されません。

## プライバシー上の注意

- 体調記録、メモ、写真をCloudflareなどのアプリ運用サーバーへ保存する機能はありません。
- IndexedDBの内容にはアプリ独自の暗号化を行っていません。
- 共有PCでは、同じブラウザプロファイルを利用する人から記録を閲覧される可能性があります。
- サイトデータやブラウザプロファイルの削除、公開URL（オリジン）の変更により、データを失う可能性があります。
- エクスポートしたZIPには健康情報や写真が含まれ、v1では暗号化されません。

## セキュリティ対策

- HTTPSと専用オリジンを前提とした本番運用
- CSP、クリックジャッキング防止、MIME sniffing防止などのセキュリティヘッダー
- 外部CDNや不要なサードパーティースクリプトを使わないビルド
- ユーザー入力をHTMLとして描画しない実装
- Production source mapを生成しない設定
- インポート内容を事前検証し、transactionで復元する処理

これらの対策はリスクを低減しますが、データの完全な安全性や永続性を保証するものではありません。

## 対応ブラウザ

原則として、Safari、Google Chrome、Microsoft Edge、Mozilla Firefoxの最新安定版を正式対応対象とします。Yahoo! JAPANアプリなどのアプリ内ブラウザはv1の正式対応対象外です。

## テスト概要

- TypeScript型チェック、ESLint、Production build
- Vitestによる日付、validation、DB transaction、migration、グラフ、バックアップ、ストレージ、UIのテスト
- PlaywrightによるChromium、Firefox、WebKitの主要ユーザーフロー
- インストール済みGoogle Chromeを利用した主要ユーザーフロー
- ユーザーによるMicrosoft Edge、macOS Safari、iPhone SafariおよびCloudflare本番環境の最終確認

詳細と確認情報の出所は[v1.0.0テスト結果](../testing/v1.0.0-test-results.md)を参照してください。

## 既知の制限事項

- ログイン、クラウド同期、端末間同期、サーバー側バックアップはありません。
- IndexedDBとエクスポートファイルはアプリ独自には暗号化されません。
- サイトデータ削除やオリジン変更によって記録を失う可能性があります。
- 別ブラウザ、別端末、別ブラウザプロファイルへは自動移行されません。
- PWA、ホーム画面追加、オフライン用静的アセットキャッシュには対応していません。
- Yahoo! JAPANアプリなどのアプリ内ブラウザは正式対応対象外です。
- 食事写真の個別削除と詳細画面からの写真差し替えは未対応です。
- 医療診断や治療提案は行いません。

## バックアップの推奨

ブラウザストレージは永続性が保証されません。設定画面から定期的にZIPバックアップをエクスポートし、安全な場所へ保管してください。バックアップは暗号化されておらず健康情報や写真を含むため、メール添付や共有ストレージでの不用意な共有を避けてください。
